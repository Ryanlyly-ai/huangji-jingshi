# 元会运世核心纪年规范

## 1. 范围

本规范只定义可以由传世文本与历史锚点稳定支持的纪年骨架：

- 历史年份与连续整数的转换；
- 元、会、运、世的层级坐标；
- 年干支与元会运世标题中的干支标签；
- 跨越本元边界时的数学延拓。

年度值卦、值爻、四象、二十四气等尚未进入核心结果。它们必须在卦序、方向和来源层级完成独立校验后再加入。

## 2. 基本常量

| 层级 | 下级数量 | 年数 |
|---|---:|---:|
| 世 | 30 年 | 30 |
| 运 | 12 世 | 360 |
| 会 | 30 运、360 世 | 10800 |
| 元 | 12 会、360 运、4320 世 | 129600 |

恒等式：

```text
1 元 = 12 会 = 360 运 = 4320 世 = 129600 年
1 会 = 30 运 = 360 世 = 10800 年
1 运 = 12 世 = 360 年
1 世 = 30 年
```

## 3. 纪元

第一元第一年采用公元前 67017 年，并令该年为甲子。

公元前 67017 年不是传世本直接标出的公历数字，而是由原书历史锚点反推：

```text
第 2232 世第 1 年序号 = (2232 - 1) * 30 + 1 = 66931
公元前 67017 年至公元前 87 年的包含首尾年数 = 67017 - 87 + 1 = 66931

第 2253 世第 1 年序号 = (2253 - 1) * 30 + 1 = 67561
公元前 67017 年至公元 544 年的连续年数 = 67017 + 544 = 67561
```

两个锚点得到同一纪元。

## 4. 无公元 0 年

对外输入采用历史纪年：公元前 1 年之后直接是公元 1 年。内部先转换为天文纪年：

```text
CE y  -> astronomical = y
BCE y -> astronomical = 1 - y
```

所以公元前 1 年对应 0，公元前 2 年对应 -1。

令纪元的天文年份为：

```text
epoch = 1 - 67017 = -67016
offset = astronomicalYear - epoch
ordinalFromEpoch = offset + 1
```

## 5. 坐标计算

先用数学模运算把 `offset` 归入某一元：

```text
yuanIndex = floor(offset / 129600)
year0 = offset mod 129600    // 结果固定为 0..129599
```

然后：

```text
元号 = yuanIndex + 1
元内年 = year0 + 1

会号 = floor(year0 / 10800) + 1
运号 = floor(year0 / 360) + 1
世号 = floor(year0 / 30) + 1

世内年 = (year0 mod 30) + 1
```

运在会内、世在运内等局部坐标按相同方法计算。

## 6. 干支标签

- 元按十干循环，第一元为甲；
- 会按十二支循环，第一会为子；
- 运按十干循环，第一运为甲；
- 世按十二支循环，第一世为子；
- 年干支以纪元甲子为索引 0，按六十甲子连续循环。

因为一世为 30 年，所以世首必然在甲子与甲午之间交替。

## 7. 边界延拓

本项目允许计算公元前 67017 年以前及公元 62583 年以后。第一元定义为 1，因此前一元记为 0，再前一元为 -1。这个编号是程序为了保持可逆性所作的数学延拓，不主张它是原书使用的历史称呼。
