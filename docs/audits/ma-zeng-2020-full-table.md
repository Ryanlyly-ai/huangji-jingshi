这证明当前实现完整复现的是**马振国、曾华才 2020 年方案**，不改变其 `MODERN_RECONSTRUCTION` 证据等级，也不证明这是邵雍唯一原法。

## 审计发现并修正的问题

全表比较发现了两个仅凭 2026 年样例不容易暴露的问题：

1. 十二会的会卦不是每会五支 2160 年值卦的首卦，而是十二消息卦：复、临、泰、大壮、夬、乾、姤、遁、否、观、剥、坤。
2. 子变卦若落乾、坤、坎、离，总表的 `Shi Hex` 仍保留四正卦原值；只有年度序列起点跳至下一支非四正卦。把调整后的年度起卦写入 `Shi Hex` 会造成 6720 行差异。

修正后，16 列全部归零差异。

## 复算方法

仓库不收录源 PDF。持有该文件的研究者可以运行：

```bash
npm install
npm run audit:ma-zeng -- "/absolute/path/to/邵雍皇极经世129,600年配卦表.pdf"
```

脚本调用 `pdftotext -layout` 读取 PDF 文本层，筛选总表 129600 行，再与算法生成值逐字段比较。也可以传入已经由 `pdftotext -layout` 生成的文本文件。

生成独立 CSV：

```bash
npm run generate:table -- --output /tmp/huangji-ma-zeng-2020.csv
```

本次审计生成物：

```text
数据行：129600（含表头共 129601 行）
字节数：10370397
SHA-256：10dc02d29b9cf0772af9e3490a1861c8ed8c3052884db3ffd8edf254f76f7dc1
```

CSV 是确定性生成物，不提交到 Git 仓库，以避免约 10 MB 的重复数据和后续仓库膨胀。算法、生成器、审计器与校验值均已提交，任何持有源 PDF 的人都可独立复核。

## 结论边界

本审计回答的是：“程序是否逐列复现该现代配表？”答案是肯定的。它不回答：“该配表的每一条选择是否都由邵雍原文明载？”后一个问题仍按证据矩阵分别处理。
