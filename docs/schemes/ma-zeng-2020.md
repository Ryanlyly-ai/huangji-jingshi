# `ma-zeng-2020` 年度配卦方案

## 定位

本模块复现马振国、曾华才 2020 年《邵雍皇极经世 129,600 年配卦表》的主要年度分配规则，并用乔宗方 2007 年论文中的 1984-2043 年序列交叉验证。

它是一个**具名、可选、可审计的现代重建**：

- 不改变 `calculateHuangji()` 的默认核心结果；
- 不声称这是邵雍唯一的年度值卦算法；
- 输出固定携带 `MODERN_RECONSTRUCTION` 和证据 ID；
- 第一元以外按 129600 年循环，是本项目明确标注的数学延伸。

## 卦数编码

采用六位伏羲二进制卦数：

- 坤为 `000000₂ = 0`；
- 乾为 `111111₂ = 63`；
- 最高位表示初爻，最低位表示上爻；
- 第 `line` 爻变动等价于 `code XOR (1 << (6 - line))`。

四正卦为坤 `0`、坎 `18`、离 `45`、乾 `63`。先天圆图顺时针数组固定为：

```text
31, 30, ..., 1, 0, 32, 33, ..., 62, 63
```

排除四正卦后得到六十值卦。元内 2160 年值卦序列再旋转到复卦 `32` 起始。

## 分层算法

令 `year0` 为目标年在一元中的零基序号，范围 `0..129599`。

### 1. 元卦、四季正卦与节卦

```text
元卦 = 复（32）
season = floor(year0 / 32400)
四季正卦 = [离 45, 乾 63, 坎 18, 坤 0][season]
termLine = floor((year0 mod 32400) / 5400) + 1
节卦 = 四季正卦变 termLine 爻
```

### 2. 会卦与 2160 年值卦

十二会采用十二消息卦：

```text
复 32、临 48、泰 56、大壮 60、夬 62、乾 63、
姤 31、遁 15、否 7、观 3、剥 1、坤 0
```

六十支 2160 年值卦则另按一会五卦分为十二组。两列在第一会和第七会等位置可能相同，但不能把会卦一概写成五卦组首卦。

```text
block2160 = floor(year0 / 2160)
2160 年值卦 = 元内六十值卦[block2160]
会卦 = 十二消息卦[floor(year0 / 10800)]
```

### 3. 360 年运卦与 60 年甲子卦

```text
within2160 = year0 mod 2160
yunLine = floor(within2160 / 360) + 1
运卦 = 2160 年值卦变 yunLine 爻

within360 = within2160 mod 360
jiaziLine = floor(within360 / 60) + 1
原始甲子卦 = 运卦变 jiaziLine 爻
```

原始子变卦保留为总表的 `Shi Hex`。如果它恰为乾、坤、坎、离之一，则只把年度序列起点沿圆图顺时针移到下一支非四正卦；不能反过来改写 `Shi Hex` 原值。

### 4. 年度值卦

```text
within60 = within360 mod 60
年度起卦 = 原始子变卦若为四正则顺时针跳过，否则保持原值
年度值卦 = 从年度起卦开始，在六十值卦数组中顺时针推进 within60 步
```

## 2026 年复算

公元 2026 年是本元第 69043 年，故 `year0 = 69042`：

| 层级 | 计算 | 结果 |
|---|---|---|
| 元卦 | 固定起始 | 复 `32` |
| 四季正卦 | `floor(69042 / 32400) = 2` | 坎 `18` |
| 节卦 | 第三季内第 4243 年，变初爻 | 节 `50` |
| 会卦 | 第七会五卦组首卦 | 姤 `31` |
| 2160 年值卦 | 第 32 组 | 大过 `30` |
| 360 年运卦 | 组内第六段，变上爻 | 姤 `31` |
| 60 年甲子卦 | 运内第五段，变五爻 | 鼎 `29` |
| 年度值卦 | 鼎起顺时针推进 42 步 | 同人 `47`，文王第 13 卦 |

该结果与 S2 总表第 69043 行一致；1984 年鼎、2019 年无妄、2043 年大过也已加入自动测试。除此之外，当前实现已与 S2 全部 129600 行、每行 16 列完成逐字段审计，差异为 0，详见[全表审计报告](../audits/ma-zeng-2020-full-table.md)。

## 调用

```ts
import { calculateMaZeng2020Allocation } from "huangji-jingshi";

const result = calculateMaZeng2020Allocation({ era: "CE", year: 2026 });
console.log(result.hexagrams.annual);
// { fuxiCode: 47, kingWenNumber: 13, name: "同人", unicode: "䷌", ... }
```

```bash
npm run calculate -- --scheme ma-zeng-2020 2026
npm run calculate -- --scheme ma-zeng-2020 --json 2026
```
