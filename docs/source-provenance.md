## 文本层次

同一册书包含不同来源层次，引用时必须分开：

1. 《皇极经世》主体及传世《观物外篇》；
2. 清代《四库全书总目提要》；
3. 附录《皇极经世机要图》，版面明确注明选自宋代张行成《皇极经世索隐》；
4. 现代整理者的标点、版式与可能的文字校订。

张行成附录可以帮助解释“一元十二会”等结构，但不能改写成“邵雍原文”。

## 当前结论的限度

- “公元前 67017 年”属于原文可推，不应写成邵雍直接使用了公元纪年。
- “公元前 2357 年”是把原书相对位置换算成现代历史纪年后的结果。
- 元会运世骨架已经进入稳定核心。
- 完整年度配卦表尚未进入稳定核心；每一个卦序与方向规则仍需逐条登记来源。
